# Physics-Challange-DIO

Este projeto foi desenvolvido como parte de um desafio da DIO, utilizando o Unity para simular física básica — sem uso de scripts.

## Sobre

A cena consiste em uma plataforma inclinada verticalmente com alguns cubos posicionados como obstáculos. Esferas com material de borracha são instanciadas no topo e colidem entre si e com os cubos, até caírem em uma área delimitada no chão.

## Recursos usados
- Unity (sem scripts)
- Rigidbody
- Colliders
- Physics Materials (para efeito de borracha)
- Cena única com objetos simples (cubos e esferas)

## Objetivo
Explorar os componentes de física da Unity, como colisões, materiais e gravidade, em uma simulação visual simples, sem pretensão de gameplay ou mecânicas avançadas.

## Status
Projeto concluído como exercício prático. Sem interações ou lógica programada.
